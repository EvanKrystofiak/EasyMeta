# EasyMeta documentation

EasyMeta shows the metadata of light- and electron-microscopy files: the
microscope, the optics, the acquisition settings and the geometry of the data.
It runs offline in a web browser and never uploads anything.

| Document | Read it when |
|---|---|
| [Quick start](QUICK_START.md) | You want to open your first file in two minutes. |
| [User guide](USER_GUIDE.md) | You want to know what every page, graphic and button shows. |
| [Supported formats](FORMATS.md) | You want to know what EasyMeta reads from a given file type, and how companion files are paired. |
| [Checks and calculations](CHECKS.md) | You want the rule and the threshold behind a check, a resolution estimate or the methods paragraph. |
| [Reports and exports](EXPORTS.md) | You want to save a report, or read the JSON / CSV export in another program. |
| [Facility setup](FACILITY_SETUP.md) | You look after shared microscope PCs and want to install EasyMeta and name your instruments. |
| [Troubleshooting](TROUBLESHOOTING.md) | Something did not open, pair or display as you expected. |
| [Developer guide](DEVELOPER.md) | You want to add a file format, a check or a graphic. |
